# 3D Scrolling Animated Website for Shoes

An immersive 3D sneaker showcase where scrolling drives the story — shoes rotate, zoom, and explode into parts as you move down the page. Built for sneakerheads who want more than a catalog: dynamic lighting, smooth parallax, and interactive product reveals that make browsing feel like unboxing.

## ✨ Features

- 🎮 **3D Scroll-Driven Animation** — Sneaker models rotate, zoom, and disassemble as the user scrolls
- 💡 **Dynamic Lighting** — Realistic lighting effects that shift with camera movement
- 🌀 **Smooth Parallax** — Layered depth for an immersive browsing experience
- 🔍 **Interactive Product Reveals** — Explosion/assembly views showing shoe components
- 📱 **Responsive Design** — Optimized for desktop and mobile viewing
